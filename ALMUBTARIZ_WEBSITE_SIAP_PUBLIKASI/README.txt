ALMUBTARIZ WEBSITE

File utama: index.html
Halaman: about.html, committee.html, countdown.html, gallery.html, video.html, contact.html
Dashboard admin: dashboard.html

CARA MENJALANKAN:
1. Ekstrak ZIP.
2. Buka folder ALMUBTARIZ_WEBSITE di VS Code.
3. Klik kanan index.html > Open with Live Server (jika ekstensi Live Server tersedia),
   atau buka index.html langsung dengan Microsoft Edge.

CATATAN PENTING:
- Dashboard admin masih berupa halaman HTML biasa dan belum memiliki sistem login/keamanan.
  Jangan publikasikan dashboard.html untuk penggunaan admin sungguhan sebelum ditambahkan autentikasi.
- Arsip awal hanya berisi file HTML; jika nanti gambar/video tidak tampil, file media perlu ditambahkan.
- Tautan Schedule lama diarahkan ke Committee karena schedule.html tidak ada di ZIP awal.
